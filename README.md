## The roast

> My microwave beeps five times, as if the first four were merely a suggestion.

One line, 77 characters — inside the 200-character gate. It roasts the
microwave, a gadget used every day, on its most recognisable habit: beeping
again and again after the food is already done, as if the first beeps were
only a suggestion.

## How it works

`main.ts` (Node 22) writes the roast to `/output/entry.txt`:

```sh
node main.ts
cat /output/entry.txt
```
